Live sports challenge solution

Turn passive match viewers into active fans

FanPulse Live is a user-friendly website system that works like a second-screen experience for cricket, football, or any live sporting event. It combines live polls, instant reactions, score prediction, and a momentum feed so fans feel involved while the match unfolds.

Starter code structure

This project is built as a single-file responsive website, so it is easy to run in a browser and also simple to convert into a Chrome extension popup or a college mini-project with backend APIs.
